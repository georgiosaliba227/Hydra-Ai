# Hydration intelligence V2 review handoff

The baseline study pipeline lacks independent evidence for a generic learned workout predictor. V2 adds supplied chronological calibration history, structured contextual comparisons and a review-only aggregate experiment policy while preserving the existing v1 APIs, numerical artifacts and participant splits.

## Resulting behavior

- System A is the existing numerical baseline. B selects bounded context, missing-data, contradiction, uncertainty and measurement-suggestion codes. C combines the authoritative numerical result with context. Synthetic fixture comparisons must keep A/C arithmetic identical.
- Longitudinal calibration uses strictly earlier comparable measurements, UTC ordering and a fixed recent-five median candidate. Ranges retain the existing full measurement envelope and may widen with earlier errors. Caller-supplied history is transient; there is no automatic persisted health-record learning.
- The Georgio-only experiment allocation is one immutable $30 gross ceiling across models and retries. $20 Spark / $10 Wonder are soft reporting targets. Reservations are atomic in the same authoritative AccountLedger object, with account thresholds, credits, expiry, finality and schema checks. Nothing initializes or migrates the private ledger.
- Financial states are deliberately review-only and incompatible with current dispatch tickets. A reviewed migration, finite approved-case manifest and dedicated live transport/settlement path remain unimplemented. There is no activation command or live endpoint for this experiment.
- New endpoints and native displays retain consent, provenance, missing-data and research/mock status. Personal measurements do not enter the contextual provider path.

## Scientific and experiment limits

Frozen QDE selected-model MAE remains 331.60 mL against 314.22 mL for its cohort baseline. No test-set optimization or independent real improvement is claimed. The fixed longitudinal candidate improves constructed drift scenarios but slightly worsens stable histories, with only 45.45% interval coverage in one gradual-drift scenario. These are simulated histories, not physiological validation.

The contextual benchmark checks local mock outputs against independent handwritten fixture labels. It cannot rank Spark and Wonder or establish real groundedness, explanation quality, latency, tokens or billing; all unobserved provider metrics stay null. Real study, synthetic-history and explanation metrics remain distinct.
