## Feature contracts

Camera uses the existing authenticated iPhone photo/consent/confirmation flow. JPEG metadata is stripped server-side. The provider returns uncertain category/brand/product/container and optional **unverified verbatim label text**. Label text never becomes nutrition or fluid accounting. Backend clients can inspect this additive field; the existing iPhone result view does not yet display label transcription. Verified nutrition remains the existing curated catalog/manual product-selection path; unknown products stay unknown, with no invented lookup IDs or hosted searches. Identity and quantity consumed require user correction/confirmation before existing deterministic logging. No iOS credentials or HealthKit export.

Amine's operator-only test uses `SyntheticContext` and `HydrationIntelligence`; no new public HTTP endpoint or iPhone hydration UI is claimed. `context_from_engine` derives intake/water using `summarize_day` with explicit day/timezone from synthetic beverage logs. Callers must explicitly attest synthetic data and disclosure consent. The bounded context contains intake, estimated composition/sweat, workout duration/intensity, weather/humidity, creatine presence and categorical feedback. Null/missing fields remain missing; intake is engine-accounted, water/sweat are estimates, and prediction is always null. No arbitrary text, raw HealthKit, identifiers, biometrics or health history enters this first test. Real HealthKit/history integration remains gated by policy review and separately scoped consent.

The model selects a small set of explanation signals. Only reviewed text is rendered, so model-generated numerical targets, diagnoses or supplement adjustments cannot escape into the result. This is deliberately constrained contextual interpretation; free-form personalized recommendations and predictive models are not implemented. Invalid schemas, refusals, incomplete results and unknown signals fail after trusted usage accounting. Request/response bodies and photos are not persisted or logged.
